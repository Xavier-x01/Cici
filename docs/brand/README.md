# cici-ai Brand Assets

Master SVG files for the cici-ai identity. Do not modify colors or mark shape without operator approval — consistency across Telegram, X, YouTube, and Locals is the goal.

## Files

| File | Use |
|---|---|
| `cici-ai-avatar.svg` | 1024×1024 square mark. Export as PNG for Telegram group photo and profile icons. |
| `cici-ai-wordmark.svg` | 1500×500 horizontal wordmark. Use as social header (X, YouTube, Locals). |

## Colors

| Name | Hex | Role |
|---|---|---|
| Navy | `#1A1D2E` | Background |
| Teal | `#3ECFCF` | Active signal / accent |
| White | `#FFFFFF` | Primary mark fill |
| Amber | `#F0C040` | Inner spark / idea node |

## Concept

A bold **C** (Cici) open to the right, with a glowing teal node at the gap. The node represents the OB1 memory connection point — active, connected, bridging. Reads legibly as initials at Telegram's ~48 px chat-list icon size.

## Export for Telegram

1. Open `cici-ai-avatar.svg` in Figma, Inkscape, or a browser.
2. Export as PNG at 1024×1024 (or 512×512 minimum).
3. In Telegram: cici-ai → group settings → Edit → Group photo → upload the PNG.
4. Check on mobile — the avatar crops to a circle; confirm the C and node are visible.

## Interim avatar (if design time is tight)

If the SVG cannot be rendered to PNG immediately, use any solid `#1A1D2E` square with the letter **C** in white as a placeholder. Almost any intentional icon beats the default empty bubble.
