# Task 5 — First Weekly Reflection

**Phase:** 1 — Personal OB1  
**Prerequisite:** Tasks 1–4 complete  
**Estimated time:** 30–45 minutes

---

## Goal

Write a structured reflection on your first month with OB1. Capture your key learnings into your own OB1 memory. Commit the journal entry to your GitHub fork so your progress is permanently visible.

This is the last task of Phase 1. It closes out the month and prepares you for Phase 2.

---

## Steps

### Step 1 — Create your journal file

In your fork, create the file:
```
docs/personal/work-journal/2026-05-<day>.md
```

Create the directory if it doesn't exist:
```bash
mkdir -p docs/personal/work-journal
```

### Step 2 — Fill in the journal

Use this template:

```markdown
# Work Journal — YYYY-MM-DD

## Phase 1 Reflection — Personal OB1

### What I did this month
- Task 1: [one sentence on the setup experience]
- Task 2: [one sentence on connecting your AI client]
- Task 3: [one sentence on capturing your context]
- Task 4: [one sentence on seeding your instance]

### What I learned about OB1
1. [First key insight]
2. [Second key insight]
3. [Third key insight]

### What was hard
[One honest paragraph. Stuck on setup? Confused by a step? That's useful to name.]

### What I would do differently
[One thing you'd change if you started again today.]

### What I want to learn next
[One capability or question you're carrying into Phase 2.]
```

Be honest. A short, real reflection is more valuable than a polished one.

### Step 3 — Capture 3 learnings into OB1

Open your AI client and ask it to capture each of your three key learnings:

> "Capture into my OB1: [your first insight]"

Do this for all three. You're building the habit of turning reflection into memory.

### Step 4 — Commit and push

```bash
git add docs/personal/work-journal/
git commit -m "journal: Phase 1 reflection — first month with OB1"
git push origin <your-branch>
```
